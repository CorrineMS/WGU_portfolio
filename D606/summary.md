# Course Summary

## D606: Data Science Capstone

**Course Status:** Completed  

D606 serves as the culminating capstone course for the Master of Science in Data Analytics (Data Science specialization). This course integrates knowledge and skills acquired throughout the program to design, implement, and communicate a comprehensive data analytics project addressing a real-world research or business problem.

---

## Course Objectives

WGU outlines the following competencies as part of this course:

- **Proposes a Data Analytics Approach**  
  Identifies a research question or business problem and proposes an appropriate data analytics strategy.

- **Implements a Data Analytics Approach**  
  Applies analytical techniques to collect, prepare, analyze, and evaluate data.

- **Communicates Information and Data Trends**  
  Uses data storytelling and visualization to present analytical findings to a non-technical audience.

---

## Practical Assessments

### Task 1: Proposing a Data Analytics Approach
Identified a real-world research question and proposed a data analytics project leveraging techniques from data science coursework. Submitted required approval and release documentation outlining the proposed analytical approach.

### Task 2: Data Analysis Report
Developed a comprehensive data analysis report that documented the research question, data collection methodology, data preparation steps, analytical techniques, and results. The report included discussion of limitations, implications, recommended actions, and future directions for analysis.

### Task 3: Presenting the Data Analysis Findings
Presented the capstone findings to a non-technical audience using a recorded Panopto presentation. The presentation summarized the problem statement, analytical process, findings, limitations, and proposed actions supported by data-driven insights.
