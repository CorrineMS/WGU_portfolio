# WGU_portfolio

## Overview

This repository documents my academic work in the **Master of Science in Data Analytics – Data Science specialization (MSDA-DS)** program at **Western Governors University (WGU)**.  
The portfolio is actively maintained and reflects coursework completed to date, as well as courses currently in progress.

The work included demonstrates applied skills in data preparation, analytics programming, statistical modeling, machine learning, optimization, deployment, data storytelling, and capstone-level project development. Artifacts are selected to showcase practical, business-focused data analytics competencies.
