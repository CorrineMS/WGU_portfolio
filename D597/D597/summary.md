# Course Summary

## D597: Data Management

**Course Status:** Completed  
**Course Dates:** August 27, 2025 – January 6, 2026  

D597 focuses on designing, implementing, and querying both relational and non-relational databases to support analytical and business requirements. The course emphasizes selecting appropriate data architectures, constructing logical and physical data models, and writing optimized queries to answer business-driven questions.

---

## Course Objectives

WGU outlines the following competencies as part of this course:

- **Recommends an Appropriate Data Architecture**  
  Evaluates business requirements to select relational or non-relational database solutions.

- **Examines the Data Available for Analysis**  
  Reviews datasets to assess structure, quality, and analytical readiness.

- **Constructs Logical Data Models**  
  Designs entity-relationship models that support analytical use cases.

- **Implements Physical Data Models**  
  Creates database schemas using appropriate data types, keys, and constraints.

- **Performs Queries to Answer Business Questions**  
  Develops queries to retrieve, aggregate, and analyze data.

- **Uses Appropriate Data Manipulation Language Statements**  
  Applies SQL and NoSQL commands to insert, update, and retrieve data efficiently.

---

## Practical Assessments

### Task 1: Relational Database Design and SQL Queries
Designed and implemented a relational database using SQL. This task included schema creation, data ingestion, query development, and optimization techniques to answer business-focused analytical questions.

### Task 2: Non-Relational Database Design and MongoDB Queries
Designed and queried a MongoDB database using JSON-formatted data. Implemented aggregation pipelines and indexing strategies to improve query performance and analytical efficiency.
