# Course Summary

## D598: Analytics Programming

**Course Status:** In Progress  
**Course Start Date:** December 18, 2025  
**Current Status:** Task 1 and Task 2 complete; Task 3 submitted and awaiting evaluation.

D598 develops programming skills for data analytics by applying computational thinking, data acquisition, data preparation, and analysis using programming tools. The course emphasizes producing reproducible analytic results and communicating outcomes through a final presentation.

---

## Course Objectives

WGU outlines the following competencies as part of this course:

- **Integrates Syntax, Control Elements, and Modular Components**
- **Performs Data Acquisition and Organization Tasks**

---

## Practical Assessments

### Task 1: Flowchart and Pseudocode (Completed)
Developed logic artifacts (flowcharts/pseudocode) to communicate program design and workflow.

### Task 2: Coding (Completed)
Implemented a Python-based analytics solution to import and analyze data, create derived metrics, validate outputs, and integrate results into a final dataset.

### Task 3: Presentation (Submitted — Pending Evaluation)
Prepared stakeholder-focused documentation and/or presentation materials to explain the solution, analysis, and results.

---

## Key Skills Demonstrated

- Python programming (pandas, NumPy)
- Data preparation and validation
- Descriptive analytics and grouping
- Derived metric creation
- Reproducible analysis and documentation
